Shepherd on the PS Vita

Shepherd runs a Unity game’s own code on a PS Vita, through a from-scratch stand-in for the Unity engine; its first game is Cult of the Lamb. Work ships in numbered “kits”: each one is built, then run on a real PS Vita and measured. Below is every trick and item in every kit, the ones done and the ones planned, each with a plain explanation and its expected effect. Numbers from kits that ran are measured on the hardware; everything else is an estimate and says so. 612 items in all. By NOVA.

How to read the effect numbers

Each item shows what it should cut: ms per frame (fewer ms = smoother), fps worked out from that at the menu’s 39.6 ms frame (kit 9, measured), seconds off boot or loading, and MB of memory or card space saved. The label says where the number comes from:

Measured on a real VitaEmulator / MacRoadmap estimateRough guessNo speed effect

The numbers don’t simply add up: many tricks overlap, and a frame only gets faster from the part that was actually slowing it down. Gameplay frames are heavier than the menu, so the same ms there is worth fewer fps (those items show no fps).

Words on this page

Frame, ms, fps
The game draws a new picture (a frame) many times a second. ms is how long one frame takes; fps is frames per second. Fewer ms = more fps = smoother.
CPU, core
The Vita’s main processor. It has 4 cores (workers); games normally get 3, and a plugin unlocks the 4th.
GPU
The graphics chip. It draws the picture while the CPU runs the game.
Memory (RAM), MB / MiB
Where the game keeps everything it’s using right now. The Vita has 512 MB; the game’s share is much smaller, and running out is what stops the Lamb walking today.
Video memory (VRAM)
A separate 128 MB for pictures and textures.
Memory cleaner (GC)
Frees memory the game no longer uses. While it works the game can pause, so a lot of tricks make it faster or move it to another core.
Interpreter, AOT, JIT
Three ways to run the game’s code: the interpreter reads it line by line (slow); AOT turns it into fast machine code ahead of time on the Mac; the JIT does that while you play.
Cache
A saved copy of work already done, so it doesn’t have to be done again.
Card
The memory card. It reads only about 10 MB a second, so loading is mostly waiting on it.
Emulator (vlx), estimate
Our copy of the Vita that runs on the Mac. Numbers from it are estimates until the Vita measures them.
Matches the original
The rule over everything: the game must look and play exactly like the PC game. Anything different is an option you choose.

  • Follower thinking skipped while nothing changed−2–10 ms

    A follower's brain runs every frame, and its needs grow a tiny bit every frame, so a plain 'nothing changed' check would never fire. The trick splits the cheap part from the expensive part: the needs keep growing every frame with the exact same maths, but the decisions (what to feel, what to do next) are skipped until a need can actually cross a line that matters, worked out ahead from its rate. Random rolls always run on schedule. (the owner's idea, 1 Nov) From the task study: 124 of the 129 tasks that run every frame qualify. Only 5 roll a random number every single frame (dissenting, ill, and scared/running-away followers) and always have to run.
